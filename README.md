# База данных отдела продаж

Проект содержит схему PostgreSQL и скрипты для заполнения базы `magazine` тестовыми данными.

## Файлы

- `schema.sql` — таблицы, типы и ограничения.
- `seed.sql` — начальные справочники и примеры операций.
- `generate_huge_data.py` — дополнительные компании, товары, курсы валют, накладные, возвраты и отчёты.
- `create-n-fill.sh` — пересоздание базы и запуск заполнения.

## Запуск

Нужны PostgreSQL, утилиты `dropdb`, `createdb`, `psql` и Python с установленным `psycopg` в `.venv`. Скрипт настроен на пользователя PostgreSQL `nitsir` и использует `sudo` для выдачи ему права `CREATEDB`.

Из каталога проекта выполните:

```sh
./create-n-fill.sh
```

**Внимание:** каждый запуск удаляет базу `magazine` вместе со всеми её данными и создаёт её заново. Имя базы задаётся переменной `DB_NAME` в `create-n-fill.sh`.

Генератор по умолчанию добавляет данные за 2025 год: 50 компаний, 200 товаров и 2000 накладных. Его параметры можно посмотреть командой `.venv/bin/python3 generate_huge_data.py --help`.
